# SDA++ 1.7.4 — Avalonia becomes the main desktop

The default source entry point, documentation and Windows package now use Avalonia. WinForms remains in the source tree as legacy.

## Included

- Startup choices and safe local SDA/SDA++ folder import.
- Download of the existing encrypted cloud credentials before batch re-login when no local file is present.
- Phone → PC and PC → Phone WebDAV profile transfer compatible with Mobile v2, using a temporary QR, separate code and encrypted payload.
- Mouse4/Mouse5 and Alt+Left/Right history; visible arrow buttons removed.
- Empty favorite/session badges hidden without an account; wider navigation, wrapped labels and responsive layouts.
- Bounded WebDAV read retries and operation-specific timeout messages; no automatic retry of writes.
- English/Russian documentation and reproducible screenshots with fictional data only.

## Install

Extract the complete Windows x64 ZIP into a new folder and run SDA++.exe. .NET is bundled. Back up the previous installation and use Account setup to import it. Encrypted data still needs its original password/key.

## Verification and limits

244 Core tests passed before release preparation; CI repeats them. Both pairing directions have local protocol/crypto tests. Real application views are rendered offline for screenshot/layout inspection.

Live provider access, physical Android pairing and Steam enrollment are not claimed as end-to-end verified. Trusted-device command/result delivery is still developing. Linux/macOS feature parity is not claimed.

No account files, manifests, credentials, personal settings, logs or debug symbols are included in the release archive.
